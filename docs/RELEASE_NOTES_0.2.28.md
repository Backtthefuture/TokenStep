# TokenStep 0.2.28

Trae CN 的积分文案改为「今用 279 / 4,321」这种「已用积分 / 当前剩余积分」的形式，并且保证数字完整显示、不再被省略号截断。

- **文案**：浮层和仪表盘「订阅额度」卡片共用同一套文本，第二项从「总额度」改为「剩余积分」（`total - used`），整数、带千分位，例如「今用 267 / 4,333」。
- **不再截断**：积分文本改为按内容自适应宽度并提高布局优先级，宽度不够时让进度条变短，而不是把数字省略成 `...`；仪表盘与浮层两处一致。
- **边界**：额度用满或超额时剩余按 0 显示，不会出现负数。
- **不受影响**：Trae 国际版仍为美元「花费」，Cursor / Codex / Claude / GLM / Kimi / Grok 仍按百分比渲染，排版不变。
- **Trae CN 的 token 消耗仍不接入 ledger**：服务端只有积分用量，本地 token 数只在 SQLCipher 加密库里，继续只展示额度。

Token、金额与额度的统计口径不变。
