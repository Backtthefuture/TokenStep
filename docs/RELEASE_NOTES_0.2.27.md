# TokenStep 0.2.27

Trae CN 的额度改用积分的真实口径显示（「已用 / 总量积分」），主窗口「今日」页新增「订阅额度」卡片；其他 provider 的百分比口径与原有排版保持不变。

- **积分口径**：Trae CN 额度窗口带上了单位标识，浮层标题显示「积分额度」，主数值改为「已用 223 / 4,600 积分」并按千分位取整，进度条按已用/总量计算，不再把积分误当成百分比显示成「本月额度 4%」。
- **订阅额度卡片**：主窗口「今日」页在分时消耗卡之后新增「订阅额度」，列出所有已启用的 provider，各自按自己的单位渲染；尚未读取到额度时会显示简短原因（未登录 / 凭证类型不对 / 登录已过期）。
- **其他 provider 不受影响**：Cursor、Codex、Claude、GLM、Kimi、Grok 等仍按百分比渲染，Trae 国际版仍按金额（美元）显示「花费」。
- **Trae CN 的 token 消耗暂不接入 ledger**：服务端只提供积分用量，没有 token 计数接口；本地每一轮的 token 数只存在于 SQLCipher 加密的 `ai-agent/database.db`，密钥不在任何可读配置或文档化钥匙串条目里。为避免伪造或估算数据，本版只展示额度，不写入 token 统计。

Token、金额与额度的统计口径不变。
