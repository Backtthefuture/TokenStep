# TokenStep 0.2.18

额度预警写明是哪个窗口会提前用完，面板里可以直接打开 Token Rank 网页。

- **预警更明确**：以前的提示只写「照此速度会提前用完」，放在服务名称旁边。如果 5 小时窗口快要重置，而实际跑快的是 7 天窗口，就容易被误读成在说 5 小时。现在提示会写出窗口名称，例如「7 天额度会提前用完」；多个窗口都会提前用完时一并列出。
- **打开 Token Rank 网页**：面板「今日排名」右上角的「榜单 N 分钟前」可以点击，会在浏览器打开 Token Rank 榜单；点击自己的排名那一行，会打开你的 Token Rank 个人主页。

统计口径与 0.2.17 相同。
