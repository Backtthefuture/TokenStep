# TokenStep 0.2.24

设置页新增 Trae（trae.ai）与 Trae CN（trae.cn）两档额度显示。开启后在凭证区粘贴登录令牌，TokenStep 会读取官方用量接口并展示当前额度窗口。

- **新增额度提供商**：Trae CN 按 credits 汇总各额度包；Trae 国际版按美元用量窗口展示。
- **凭证只进钥匙串**：客户端登录态是本地加密存储，TokenStep 不解析客户端私密文件，改为手动粘贴访问令牌，随时可清除。
- **设置页引导**：凭证区直接给出获取令牌的四个步骤，令牌过期后重新粘贴即可。
- **未纳入 Token 统计**：Trae 本地用量库为加密存储，按现有接入规则（只读明文 usage 字段、不用字数估算）暂不进入正式统计。

Token、金额与额度的统计口径不变。
