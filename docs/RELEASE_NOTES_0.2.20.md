# TokenStep 0.2.20

面板里和时间有关的信息保持最新，修复几处细节问题。

- **额度到点重置**：额度窗口过了重置时间，改为显示「已重置」，不再显示旧的百分比；TokenStep 会在最近一次重置后约 30 秒自动重新读取额度，不用等到下一轮刷新。
- **面板开着也会走时**：「17 分钟后」「1 分钟前」、额度条上的时间进度竖线和「会提前用完」的判断，面板一直开着时也会每分钟更新。
- **刘海卡片**：在「…」菜单里选完操作后，如果鼠标停在卡片顶部，卡片不再意外收起。
- **鼠标指针**：从榜单链接上关掉面板后，鼠标指针不再停留在手形。

Token、金额与额度的统计口径不变。
