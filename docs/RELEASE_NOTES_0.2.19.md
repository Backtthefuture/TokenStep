# TokenStep 0.2.19

面板的额度和排名更精简，重点更突出。

- **额度条统一粗细**：带时间进度竖线的额度条和不带竖线的一样粗。Cursor 的两类模型额度按每月账单周期显示时间进度竖线。
- **名称与图标**：Cursor 自有模型的额度改名为「自带」；没有安装 Grok App 时，额度区也显示 Grok 图标。
- **排名更聚焦**：只有你在前 10 名时才显示前三名；去掉每行的「差多少」和「榜上」总数，改为显示离你最近的后一名以及你领先多少。北京时间下，追赶差距会把还没同步到榜单的本地用量算进去。
- **数字更紧凑**：大数字后的「亿」「万」字号略小，紧贴数字。
- **页脚更简洁**：去掉刷新间隔的文字。

Token、金额与额度的统计口径不变。
