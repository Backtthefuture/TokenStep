# TokenStep 0.2.16

菜单栏面板改成一列 340pt 的紧凑面板，在 13 寸屏幕上不再被截掉；额度刷新更及时。

- **紧凑面板**：以前的面板宽 900pt，在 13 寸屏幕上左侧会被截掉。现在只放三块最常看的内容：额度、今日 Token、今日排名。分享、截图、退出收进「…」菜单；客户端明细和完整模型列表仍在仪表盘里。
- **刘海 Mac 同步改版**：点刘海旁的 Token Island 打开的也是同一个新面板，高度跟随内容变化。
- **额度更好懂**：每行额度的竖线表示这个窗口的时间已经过去多少；用量跑在时间前面时，会提示「照此速度会提前用完」，并标出是哪一行。鼠标停在某一行上可以看到具体数字。
- **额度刷新更及时**：面板打开时最多每 5 分钟刷新一次额度（以前最长可能 25 分钟才更新），点刷新按钮或按 ⌘R 会立即刷新额度。偶尔查询失败时保留上一次读数，不再整行消失。后台刷新频率不变。
- **Claude Code 图标**：只用 Claude Code CLI、没有安装 Claude 桌面 App 时，额度区也显示 Claude 的图标。
- **排名**：今天还没上榜时显示「未上榜」，不再显示一条横线；「再跑多少超过下一名」的字号调小。

Token、金额与额度的统计口径不变。
