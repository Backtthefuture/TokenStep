# TokenStep 0.2.21

仪表盘和设置改版，参考 Token Rank 个人页，更简洁、信息更集中。

- **今日**：圆环旁显示与昨天同一时间相比多了还是少了，以及 Token 构成（输入、缓存读取、输出）和缓存命中率。四张指标卡显示估算金额、活跃时长、模型请求与今日排名。新增「近 5 周」热力图和连续达标天数，可一键跳到历史。分时图按客户端堆叠，鼠标移到任意一小时即可看到当时的总量和各客户端用量。
- **历史**：顶部是累计 Token、估算金额、活跃天数和最长连续达标。热力图随窗口宽度显示近一年，旁边是近 30 天的常用时段。近 30 天趋势旁可切换查看各客户端或各模型的累计占比。每日明细默认显示 7 天，可展开全部，新增「达标」一列，并可导出 CSV。
- **设置**：改为左侧栏导航（通用、外观、数据源、额度、Token Rank），每页的选项一行一个、按组排列。改动立即生效，不再需要点「完成」。主题皮肤移到「外观」，Token Rank 有了单独的页面。
- 去掉了界面上面向开发者的说明文字。

Token、金额与额度的统计口径不变。
