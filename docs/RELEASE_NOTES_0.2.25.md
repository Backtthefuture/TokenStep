# TokenStep 0.2.25

Trae 与 Trae CN 额度改为「用浏览器登录」一键获取凭证，原先的粘贴令牌方式降级为兜底。

- **浏览器登录（推荐）**：设置页点「用浏览器登录」，会用系统浏览器打开 trae.cn / trae.ai 的官方授权页，授权完成后自动回跳本机并把令牌写入钥匙串，不需要手动找令牌。
- **令牌自动续期**：同时保存 refresh token，访问令牌过期时自动换取新令牌并重试；刷新也失效时才提示重新登录，失败原因会直接显示，不会静默。
- **手动粘贴仍是兜底**：原有输入框与「保存并检测」保留，适合浏览器授权不可用或临时排障。
- **本机登录态无法读取**：客户端把登录态存在私有加密块里（storage.json 的 iCubeAuthInfo 非 Electron v10 格式），TokenStep 不解析客户端私密文件，也不会抓取浏览器 cookie。
- **凭证只进钥匙串**：访问令牌与 refresh token 都只保存在 TokenStep 自己的钥匙串条目里，清除密钥会一并删除。

Token、金额与额度的统计口径不变。
