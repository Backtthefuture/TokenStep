岛上只显示一家额度。现在写死 Codex+Claude 两个 mini 条，多提供商后会挤爆。改成「剩余最少的一家」，因为岛的价值是提前预警，不是罗列。

底栏不变量

任何状态下：打开仪表盘 / 刷新 / 设置 / 退出 四个动作都在，位置不动。内容栏可以消失，动作不行。

深色配额

全窗只允许两处深色：菜单栏 T 标识、榜栏「全榜今日消耗」小卡。出现第三处就是走偏了。

L2 / L3 隔离

Cursor 的美元与代码行数不进圆环、不进总量、不进榜单。只出现在额度栏与 Agent 栏底部一行。

失败不写 0

额度失败显示「暂不可用」+ 上次值 + 时间。0% 等于误报额度耗尽。
